# Prompt 04 — Composição e Análise da Fatura

## Objetivo

Aprofundar a leitura técnica e comercial de uma fatura de energia elétrica, separando os componentes relacionados à energia dos componentes relacionados ao uso da rede.

## Prompt utilizado

> Com base exclusivamente nas fontes selecionadas, explique detalhadamente a composição de uma fatura de energia elétrica, separando os componentes relacionados à energia dos componentes relacionados ao uso da rede. Explique TE, TUSD, consumo, demanda, ultrapassagem, encargos, perdas e tributos. Para cada item, informe: o que é, unidade de medida, quem cobra, como aparece na fatura e qual é sua importância para uma análise comercial. Ao final, apresente um checklist prático para um Executivo de Negócios analisar uma fatura antes de avaliar um cliente. Cite as fontes utilizadas em cada item.

## Resultado obtido

O NotebookLM estruturou a análise dos seguintes componentes:

1. TE — Tarifa de Energia;
2. TUSD — Tarifa de Uso do Sistema de Distribuição;
3. Consumo;
4. Demanda;
5. Ultrapassagem;
6. Encargos Setoriais;
7. Perdas;
8. Tributos.

A resposta também separou os componentes em:

- **Energia / Molécula**
- **Uso da Rede / Fio**

Além disso, foi criado um checklist para apoiar a análise comercial de uma unidade consumidora.

## Aprendizado

O prompt transformou o conhecimento sobre faturamento em uma estrutura operacional de análise.

A principal evolução foi passar da simples identificação de conceitos para uma visão prática, considerando:

- o que é cada componente;
- unidade de medida;
- responsável pela cobrança;
- forma de apresentação;
- importância para a análise comercial.

## Aplicação Profissional

A estrutura pode ser utilizada como base para análises futuras de clientes, permitindo organizar informações de consumo, demanda, tarifas e demais componentes antes de uma avaliação comercial.

## Observação

A resposta do NotebookLM foi utilizada como material de estudo baseado nas fontes selecionadas. Informações regulatórias, tarifárias, tributárias ou comerciais específicas devem ser verificadas diretamente nas fontes de origem antes de qualquer utilização profissional.
